辅助功能

剧情流线模式

开启后，双语编辑器会按玩家实际体验的剧情流程排列 Map 文件中的对话、选项与分支文本；System / Database / CommonEvents 等文本仍保持原顺序。修改译文后写回 JSON 时仍使用原始物理位置，确保游戏结构安全。

自动保存

开启后，程序会按间隔自动覆盖写入 auto-save 文件；手动保存的文件不会被覆盖。自动保存文件可用于崩溃恢复。

Kimi（月之暗面）配置教程
  1. 1. 选择端点：Kimi 有两条独立端点，密钥不通用：
    · 国际版：登录 platform.kimi.ai，对应 base_url https://api.moonshot.ai/v1。
    · 国内版：登录 platform.moonshot.cn，对应 base_url https://api.moonshot.cn/v1。
    务必把 Key 与其来源端点配对，跨端点使用会得到 HTTP 401 Invalid Authentication。
  2. 2. 在对应控制台的「API Keys」页面点击「新建 API Key」，复制 sk- 开头的密钥，粘贴到上方「API Key」输入框（右侧眼睛可切换显示）。
  3. 3. 「接口地址」按你的账号来源二选一填：https://api.moonshot.ai/v1（国际）或 https://api.moonshot.cn/v1（国内）。必须带 /v1，程序自动拼 /chat/completions。
  4. 4. 模型下拉里推荐日常翻译选 moonshot-v1-8k（8K 上下文最便宜）；长文本或整段对话可选 moonshot-v1-32k / moonshot-v1-128k；追求最强质量可选 kimi-k2.6。
  5. 5. 已停用：kimi-latest（2026-01-28 下线）与 kimi-k2-*-preview 系列（2026-05-25 下线），不要使用。
  6. 6. 保存后点击「测试大模型翻译」验证；若得到 401 大概率是端点与 Key 来源不匹配，请回控制台核对来源与余额后重试。

功能介绍与教程

项目与引擎识别

汉化工作的第一步是把游戏项目导入工作台。程序会自动识别常见 RPG 引擎的项目结构。

  • 点击侧边栏「打开游戏项目」，选择游戏根目录。
  • 工作台会自动判断 RPG Maker MV/MZ、Wolf RPG、Kirikiri 等引擎，并显示引擎徽章。
  • 如需补充扫描额外文本目录，可点击「扫描文本位置」。
  • 载入后，工作区会显示文本组数、翻译进度和术语命中统计。

双语编辑器

编辑器以原文/译文对照的形式列出所有可翻译文本，支持单条模式和上下文组模式。

  • 通过「JSON 文件」下拉框切换不同数据文件；使用搜索框快速过滤关键词。
  • 「单条模式」适合逐句精修；「上下文组模式」可把相邻对话组成一段整体翻译后自动拆分。
  • 进度仪表盘显示项目全局进度、当前文件进度和上次翻译位置，方便断点续翻。
  • 点击译文行状态标签可切换「已翻译/未翻译/已校对」，便于进度管理。

辅助翻译

工作台内置传统机器翻译与大型语言模型两种辅助方式，可按需配置后一键翻译单条或编组文本。

  • 在「设置 → 传统翻译」中配置百度或 Google 翻译 API。
  • 在「设置 → 大模型翻译」中配置 DeepSeek、Kimi、Gemini、Claude 或自定义 OpenAI 兼容接口。
  • 编辑器的每行右侧会出现「AI 翻译」按钮；上下文组模式下可调用 AI 翻译整组。
  • 术语库开启后，可在 AI 调用前强制替换原文或注入系统提示词，保证译名一致。

术语库

术语库用于统一游戏内的专有名词译法，支持多子库、分类和导入导出。

  • 侧边栏点击「管理术语库」，或在设置中进入「术语库」标签。
  • 可新建多个术语库并按分类聚合；同分类下的子库会一起参与命中。
  • 命中术语会在编辑器中高亮显示，并可一键插入到译文。
  • 支持从 CSV/JSON 导入和导出，方便与团队成员共享术语表。

导出与写回

翻译完成后，可导出草稿备份、生成可回写的补丁目录，或直接把译文写回新的游戏 JSON。

  • 「导出草稿」把当前所有译文保存为 JSON 草稿，便于备份与团队协作。
  • 「导出补丁」生成只包含译文的补丁目录，可在不破坏原项目的情况下测试。
  • 「写回游戏 JSON」会按原数据结构输出到新目录 localization_patch/data/，不会覆盖原始文件。
  • 写回前建议先导出草稿备份，写回后可点击「打开补丁目录」查看结果。

游戏内预览

在 RPG Maker MV/MZ 项目中，可直接启动游戏预览，实时查看译文在游戏里的显示效果。

  • 在「设置 → 辅助功能」中启用游戏内快速预览，并选择弹出窗口或嵌入主窗口。
  • 在编辑器中点击译文行的「预览」按钮，程序会自动定位到对应游戏事件。
  • 预览期间原 JSON 会被临时替换，关闭预览或点击「停止游戏预览」后自动恢复备份。
  • 使用预览窗口的「上一句/下一句」可快速切换当前查看的文本。

个性化设置

通过设置面板可以调整界面语言、配色、字体、关闭行为和自动保存等选项。

  • 「界面设置」支持简体中文、English、日本語，并可更换主题色与背景图。
  • 「辅助功能」可开启剧情流线模式、自动保存和游戏内预览。
  • 「其他」中可设置草稿保存目录、界面字体，以及查看项目版本与功能导览。
